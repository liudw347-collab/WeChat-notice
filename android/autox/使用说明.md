> **目标**：让任何老师 5 分钟内装好，不用懂电脑。

## 📱 你只需要做 3 件事

### 第 1 步：下载安装 AutoX.js APP

⚠️ 必须用下面的链接下载，**应用商店搜不到**

**下载链接**（任选一个，哪个能打开用哪个）：

1. **GitHub 加速版**（推荐）：
   ```
   https://ghproxy.com/https://github.com/aiselp/AutoX/releases/download/v9.3.2/AutoX.js-v9.3.2-arm64-v8a.apk
   ```

2. **GitHub 直连版**（网络好可试）：
   ```
   https://github.com/aiselp/AutoX/releases
   ```
   找最新版本，下载名字带 `arm64-v8a` 的 APK

3. **手机浏览器扫码**：让 IT 老师生成二维码给你扫

安装时如果提示"出于安全考虑，禁止安装"，请去设置允许"安装未知来源应用"。

### 第 2 步：导入安全提醒脚本

1. 下载脚本文件 `safety-reminder.js`：
   ```
   https://ghproxy.com/https://raw.githubusercontent.com/liudw347-collab/WeChat-notice/main/android/autox/safety-reminder.js
   ```
   （或者直接从项目 zip 包里复制这个文件到手机）

2. 打开 AutoX.js APP
3. 点右下角 **"+"** → **导入** → 选择刚下载的 `safety-reminder.js`
4. 看到脚本列表里出现 "safety-reminder" 就成功了

### 第 3 步：开启权限 + 运行

打开 AutoX.js 后，按提示开启以下权限（**全部要点允许**）：

1. **无障碍服务**：APP 会自动跳转到设置页 → 找到 "AutoX.js" → 开启
2. **悬浮窗权限**：设置 → 应用 → AutoX.js → 显示在其他应用上层 → 允许
3. **截屏权限**：第一次运行脚本时会弹窗，点"允许"
4. **存储权限**：第一次运行时会请求

然后回到 AutoX.js，**点击 "safety-reminder" 脚本运行**：
- 第一次运行会弹出**配置界面**
- 输入班级群名、班主任群名（**从微信里长按群名复制粘贴**）
- 选择发送时间（默认 7:30）
- 点"保存配置"

会回到主界面，可以看到：
- **测试发送**：发到文件传输助手，不影响真实群
- **立即发送一次**：直接发到真实群
- **修改配置**

点"测试发送"，如果文件传输助手收到了消息+截图，就成功了！🎉

## ⚠️ 必须做的设置（不然手机睡眠就不工作了）

### 1. 关闭 AutoX.js 电池优化

**设置 → 应用 → AutoX.js → 电池/耗电管理 → 不限制后台活动**

> 这一步**最关键**！否则手机锁屏后脚本会被杀掉，定时任务不执行

### 2. 锁定 AutoX.js 后台

打开 AutoX.js 后，**最近任务列表里下拉 AutoX.js 卡片 → 锁定**（出现锁图标）

### 3. 允许自启动

- **小米/红米**：安全中心 → 应用管理 → 自启动管理 → AutoX.js 开启
- **华为/荣耀**：设置 → 应用启动管理 → AutoX.js → 手动管理（三个开关全开）
- **OPPO/vivo**：设置 → 电池 → 应用冻结 → AutoX.js 设为"不允许冻结"
- **三星**：设置 → 电池和设备维护 → 电池 → 后台使用限制 → 不限制 AutoX.js

### 4. 屏幕锁设置

脚本会自动上滑解锁，但**无法输入密码**。建议：
- 设置智能解锁（到家时保持解锁）
- 或早上 7:30 之前不锁密码
- 或用专门的旧手机不锁屏

### 5. 长期插电

用旧手机长期插电运行最稳，避免省电模式。

## 🛠️ 常见问题

**Q1：下载 APK 提示"解析失败"**
A：你下载的是 `arm64-v8a` 版本，老手机可能需要 `armeabi-v7a` 版本。去 GitHub releases 页找对应版本。

**Q2：脚本运行后没反应**
A：① 确认无障碍服务已开启（设置→无障碍→AutoX.js）；② 确认 AutoX.js APP 没被杀掉。

**Q3：搜索群名时找不到**
A：**长按微信群名 → 复制 → 粘贴到配置里**，不要手打（容易打错）。

**Q4：脚本运行了但没发出去**
A：观察手机屏幕，看卡在哪一步。如果是找不到按钮，可能是微信版本变了，联系 IT 老师调整脚本。

**Q5：今天没自动执行**
A：① 检查电池优化是否关闭；② 检查 AutoX.js 是否在后台运行；③ 打开 APP 一下，触发重新启动。

**Q6：手机重启后不工作了**
A：打开 AutoX.js APP 一下，再点击运行脚本一次（脚本会自动重新设置定时任务）。

**Q7：怎么修改群名/时间**
A：打开 AutoX.js → 点击 safety-reminder 脚本运行 → 点"修改配置"。

**Q8：暑假结束后怎么停用**
A：打开 AutoX.js → 长按 safety-reminder 脚本 → 停止。或直接卸载 AutoX.js APP。
