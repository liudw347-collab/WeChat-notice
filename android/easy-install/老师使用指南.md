# 定州市第八中学 安全提醒 · 老师使用指南

> 让任何老师都能在 5 分钟内装好用的安卓版方案

---

## 📋 老师需要准备的

- 一部安卓手机（Android 7+，建议用专门的旧手机长期插电）
- 微信已登录
- 网络连接

## 🚀 5 步搞定（不需要懂电脑）

### 第 1 步：安装 2 个 APP

⚠️ **必须用 F-Droid 版**，应用商店版不能用

| APP | 下载链接 | 用途 |
|-----|---------|------|
| Termux | https://f-droid.org/packages/com.termux/ | 终端环境 |
| Termux:API | https://f-droid.org/packages/com.termux.api/ | 通知/震动告警 |

> 💡 **快速方法**：用微信扫描下方二维码（在电脑端打开本文件可见），可直接跳转下载页

### 第 2 步：打开 Termux，复制粘贴下面这一行命令

打开 Termux APP，长按屏幕 → 粘贴 → 回车：

```
curl -fsSL https://raw.githubusercontent.com/liudw347-collab/WeChat-notice/main/android/easy-install/bootstrap.sh | bash
```

> 如果上面命令卡住（GitHub 网络问题），改用国内加速版：
> ```
> curl -fsSL https://ghproxy.com/https://raw.githubusercontent.com/liudw347-collab/WeChat-notice/main/android/easy-install/bootstrap.sh | bash
> ```

### 第 3 步：按提示完成配置向导

脚本会引导你输入：
- ✅ 班级微信群名（从微信里**复制**群名粘贴过来，不要手打）
- ✅ 班主任工作群名
- ✅ 发送时间（默认 7:30）

### 第 4 步：测试一次

向导最后会问"是否测试发送"，选 Y：
- 手机会自动打开微信
- 切到"文件传输助手"
- 发出一条测试消息 + 一张截图

如果都收到了，说明配置成功！

### 第 5 步：关闭电池优化（**最关键，必做！**）

否则手机睡眠后 Termux 会被系统杀掉，定时任务不执行：

1. **设置 → 应用 → Termux → 电池 → 不受限**
2. **设置 → 应用 → Termux:API → 电池 → 不受限**
3. **设置 → 应用 → ATX → 电池 → 不受限**
4. **Termux 通知栏长按 → 锁定**（防止被清理）
5. **自启动管理允许 Termux**：
   - 小米/红米：安全中心 → 应用管理 → 自启动管理 → Termux 开启
   - 华为/荣耀：设置 → 应用启动管理 → Termux → 手动管理（三个开关全开）
   - OPPO/vivo：设置 → 电池 → 应用冻结 → Termux 设为"不允许冻结"

## 🎯 完成！每天自动运行

第二天起，每天早上 7:30 手机会自动：
1. 唤醒屏幕
2. 打开微信
3. 在班级群发安全提醒文案
4. 截图
5. 在班主任群发截图
6. 关闭微信

如果失败，手机会**长震动 + 通知栏弹窗**提醒老师手动补发。

## ❓ 老师常见问题

**Q1：第一天装好后，第二天没自动发**
A：① 确认关闭了 Termux 的电池优化；② 在 Termux 通知栏长按"锁定"；③ 在手机自启动管理中允许 Termux；④ 长期插电。

**Q2：测试时手机没反应**
A：① 确认 ATX 应用已启用；② 重新初始化：`python -m uiautomator2 init`；③ 检查无障碍服务中 ATX 是否启用。

**Q3：搜索群名时搜不到**
A：从微信里**长按群名 → 复制**，然后粘贴到配置向导，**不要手打**（容易打错）。

**Q4：手机重启后不工作了**
A：打开 Termux APP 一下（不用做任何操作），wake-lock 就会自动恢复。

**Q5：微信更新后失效**
A：升级依赖：`pip install -U uiautomator2`，或重新拉取项目代码：
```
cd /storage/emulated/0/WeChat-notice && git pull
```

**Q6：能改发送时间吗？**
A：重新运行配置向导：`python /storage/emulated/0/WeChat-notice/android/easy-install/config_wizard.py`

**Q7：暑假结束了怎么卸载？**
A：
```
crontab -l | grep -v wechat_daily_android.py | crontab -
termux-wake-unlock
```
然后卸载 Termux / Termux:API / ATX 三个 APP 即可。
